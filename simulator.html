Model and equations

Temperature-dependent extraordinary/ordinary index of 5 mol% MgO:CLN, in the Sellmeier form given in the HC Photonics guide (coefficients of Gayer et al., Appl. Phys. B 91, 343 (2008)), λ in µm, T in °C:

n²(λ,T) = a1 + b1·f + (a2 + b2·f)/(λ² − (a3 + b3·f)²) + (a4 + b4·f)/(λ² − a5²) − a6·λ² f = (T − 24.5)(T + 570.82)

Quasi-phase-matching with thermal expansion of the grating, Λ(T) = Λ₀[1 + α(T−25) + β(T−25)²], α = 1.54×10⁻⁵ K⁻¹, β = 5.3×10⁻⁹ K⁻²:

Δk = 2π [ n_p/λ_p − n_s/λ_s − n_i/λ_i ] − 2π m / Λ(T) φ(ω_s, ω_i) = sinc(Δk L / 2) d_eff = (2/π) d_ij / m

Polarisations, labelled signal · idler · pump: Type-0 eee (e → e + e) via d₃₃ = 25.3 pm/V; Type-I ooe (e → o + o) via d₃₁ = 4.85 pm/V; Type-II eoo (o → e + o) or oeo (o → o + e) via d₃₁ (= d₁₅ under Kleinman symmetry). The two Type-II choices swap which photon is extraordinary, so they need different periods away from degeneracy. The d values are the ones quoted in the guide.

Purity is computed from a 96×96 sampled JSA as Tr(ρ²) = Tr[(JJᵀ)²]/Tr[JJᵀ]², with K = 1/purity. For a CW pump the JSA collapses onto the anti-diagonal; the map is broadened only for display and purity → 0.

Not modelled: focusing (Boyd–Kleinman / Bennink), absolute pair rates, waveguide dispersion, poling duty-cycle errors, non-collinear emission.

Material model from the HC Photonics PPLN guide · Sellmeier coefficients of Gayer et al., Appl. Phys. B 91, 343 (2008). Source on GitHub
