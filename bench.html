How the fit works

The model is the one used by the simulator: temperature-dependent Sellmeier indices of 5 mol% MgO:CLN, grating thermal expansion and Δk = 2π[np/λp − ns/λs − ni/λi] − 2πm/Λ(T), with the polarisations set by the interaction type.

Spectrum S(λ) = A · ⟨sinc²(Δk L/2)⟩ + B ⟨⟩ = average over pump BW and resolution Tuning curve λ(T) solves Δk(λ, T + ΔT) = 0 nearest root to each measured point Acceptance C(T) = A · ⟨sinc²(Δk(λ_f, T + ΔT) L/2)⟩ + B JSI I(λs, λi) = A · |exp(−2 ln2 Δσ²/Δσ_p²) · sinc(Δk L/2)|² + B

The nonlinear parameters you tick are fitted by Levenberg–Marquardt with numerical derivatives. Amplitude A and background B are solved by linear least squares at every step, so they never need starting values. ΔT is an offset added to the recorded oven temperatures.

Count data default to Poisson weights 1/√counts. Use Unweighted only for data that are not raw counts (normalised or background-subtracted spectra). With raw counts it still finds the best curve, but its error bars come out too small because bright pixels are much noisier than dim ones.

Uncertainties are 1σ from the covariance (JᵀJ)⁻¹ scaled by the reduced χ², as in scipy's curve_fit default. Pairs of parameters with |correlation| above 0.95 are flagged, since Λ₀, T and ΔT often trade off against each other. Fit one of them and hold the others.

Sinc² fits have many local minima. Press Auto guess first: it places the phase-matching peak on the data peak and sets L from the measured width. The rack values are always the starting point, so you can also set them by hand while watching the model curve.

JSI purity is estimated from √(data − B) as the joint spectral amplitude, assuming a flat spectral phase, so it is an upper bound for the real state. The model purity uses the fitted JSA. Overlap is the Bhattacharyya coefficient between normalised data and model.

Material model from the HC Photonics PPLN guide · Sellmeier coefficients of Gayer et al., Appl. Phys. B 91, 343 (2008). Source on GitHub
